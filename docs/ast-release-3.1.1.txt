AST 3.1.1 / 웹 0.1.1+2 — 2026-10-25

포함 기능
1. 기여도: GitHub Raw의 공개 기여도만 직접 GET. 지갑 수령/가구 구매는 기존 서버 그대로.
2. Transit Live: 모임의 시간을 지켜주는 실시간 지하철 정보.
   https://serenlucent.github.io/TransitLive/ 를 별도 화면에 연결.
   Android는 WebView, 웹은 격리 iframe. AST 비밀번호/세션/구매 브리지는 전달하지 않음.
3. 양쪽 관리자 '멤버 관리': 앱 최근 접속 / 웹 최근 접속을 구분해 표시.
   웹 기록은 GitHub가 아니라 웹용 Apps Script 비공개 속성에 저장.
   기록하는 값은 로그인 ID와 서버 접속 시각뿐. IP/기기 식별자/비밀번호는 기록하지 않음.
   로그인, 자동 로그인, 로그인 상태에서 화면 복귀 시 기록. 지속적인 백그라운드 추적 없음.
   화면 복귀 알림은 1분 이내 중복 전송을 줄임. 온라인 서버 확인이 성공한 접속만 기록.
   기존 앱 접속 기록의 저장 방식은 변경하지 않음.

필수 서버 적용 — 웹용 프로젝트만
1. D:/MyProject/AST/web-app/server/Code.gs 전체를 복사.
2. 기존 'AST 웹 로그인용' Apps Script 프로젝트의 Code.gs 전체를 교체하고 저장.
   Android 일정/아스트/구매용 apps-script/Code.gs와 혼동하지 말 것.
3. 기존 WEB_PASSWORD, WEB_ADMIN_PASSWORD, LEGACY_API_URL, LEGACY_APP_KEY 등 속성 유지.
   새 속성이나 비밀번호 길이 제한은 없음.
4. 배포 → 배포 관리 → 기존 웹앱 수정(연필) → 버전 '새 버전' → 배포.
   기존 /exec 주소를 유지. 코드 저장만으로는 운영 /exec 버전이 바뀌지 않음.
5. /exec 주소의 공개 상태 응답 revision이 private-web-access-v1인지 확인.
   상태 응답에는 접속 기록이나 비밀 값이 없음.

확인 방법
- 웹: 관리자 로그인 → 멤버 관리 → 웹 최근 접속 확인 / 새로고침.
- Android: 3.1.1 설치 → 관리자 로그인 → 멤버 관리 → '웹 관리자 인증'.
  웹 관리자 아이디와 WEB_ADMIN_PASSWORD를 입력. 일반 공용 비밀번호와 다를 수 있음.
  비밀번호는 저장하지 않음. 조회 전용 인증은 화면을 닫으면 폐기하고 로그아웃을 시도함.
  서버의 조회 전용 세션은 15분 미사용 시 만료. 일반 웹 로그인 유효기간은 기존 30일 유지.
  조회 전용 토큰으로 지갑 수령/가구 구매/정보 변경을 요청할 수 없음.
- 서버 배포 전에는 웹 기록 조회 오류나 '웹용 Apps Script 재배포' 안내가 나올 수 있음.
  Transit Live, 기여도 조회, 기존 로그인/구매는 해당 서버 배포와 별개.
- 기능 적용 이전의 웹 접속은 소급 복구하지 않음. 기록 없음은 접속한 적이 없다는 단정이 아님.
- 웹 주소: https://serenlucent.github.io/AST/ast-web/
- Android: 앱의 업데이트 확인 또는 update/AST-3.1.1.apk 덮어 설치. 기존 앱 삭제 불필요.
