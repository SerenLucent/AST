# 내장 피아노 음원

piano.sf2: Nando Florestan의 Florestan 음원 subset, TinySoundFont 예제에서 제공.
다운로드: https://github.com/schellingb/TinySoundFont/blob/master/examples/florestan-subset.sf2
Florestan 피아노의 public domain 표기: https://www.polyphone.io/en/soundfonts/pianos/281-000-florestan-piano
원본 파일의 INFO 메타데이터는 그대로 유지합니다. 배포 전 최종 음원의 출처 및 라이선스를 다시 검토하세요.

합성 엔진: dart_melty_soundfont 2.0.0 (MIT)
https://github.com/chipweinberger/dart_melty_soundfont

이번 테스트에서는 모든 파트를 bank 0/program 0 피아노로 연주합니다. 타악기 원래 음색은 아직 반영하지 않습니다.
