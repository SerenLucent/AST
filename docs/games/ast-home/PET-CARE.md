# 모모와 쿠키 돌보기

캐릭터 원본은 커플앱 `TwoPlace/public/pets`의 모모(mochi)·쿠키(kuki) 정면/측면/뒷면 이미지다. 256px WebP로 제공하며 집 안의 빈 바닥을 자동으로 돌아다닌다. 캐릭터는 선택·수동 이동 대상이 아니며 화면 확대와 드래그를 방해하지 않는다. 테라스와 1·2층 모두 하단에 별도의 돌보기 카드를 표시한다.

- 먹이는 무료, 한 번에 포만감 +20 및 해당 사용자 지갑 +1 AST.
- 포만감 80 이하에서만 먹이주기 가능. 81 이상은 “아직 배불러요”.
- 최대 100, 6분마다 1 감소(시간당 10), 최초 포만감 75.
- A·B가 동시에 0을 불러온 뒤 각각 5번 주면 모두 5 AST를 받는다. 공유 포만감은 100으로 제한하고 다음 입장자는 공유 수치를 읽는다.
- 각 사용자의 급여 기록은 자기 화면의 80 제한을 서버에서도 지키기 위한 기록이다. 다른 사용자의 급여 때문에 보상을 거절하지 않는다.
- 클라이언트는 포만감과 보상을 먼저 표시하고 계정별 저장된 대기열에서 비동기로 전송한다. 같은 요청의 재전송은 보상을 중복 지급하지 않는다. 응답을 기다리는 동안 캐릭터·확대·방 전환·메뉴를 잠그지 않는다.
- AST 지급과 공유 포만감은 GitHub에 저장된다. 기존 집 저장/지갑 복구 절차를 재사용한다. 먹이 보상은 가구 구매 기여도에 합산하지 않는다.

## 실제 앱에 적용

기존 **AST GitHub API** Apps Script 프로젝트의 `Code.gs`를 저장소의 `apps-script/ast-home/Code.gs` 전체 내용으로 교체하고 **기존 웹 앱 배포를 새 버전으로 업데이트**한다. 기존 Script Properties와 URL을 유지한다. 별도의 스크립트 프로젝트를 만들거나 Android APK를 새로 빌드할 필요가 없다. 기존 인증된 `astHomeApply` 브리지를 사용한다.

서버를 아직 업데이트하지 않았다면 캐릭터는 보이지만 실제 계정의 먹이주기는 비활성화하고 서버 업데이트 안내를 표시한다. 테스트 페이지는 기존 10,000 TEST AST와 함께 독립된 로컬 포만감을 사용하며 실제 지갑을 변경하지 않는다. 테스트 초기화는 포만감도 초기화한다.

## 검증

`test/ast_pet_care.test.mjs`: 즉시 +20/+1, 80/81·99 경계, 시간 감소, 오프라인 재전송, 대기열 복원.
`test/ast_pet_server.test.cjs`: 동시 A·B 각 5 AST, 공유 100 제한, 개별 급여 제한, 시퀀스 재전송 중복 방지, Git 저장 후 지갑 쓰기 중단 복구.
브라우저 검증: 실제 테라스/실내 모바일 화면, 자동 이동, 화면 확대, 입장 간 잔액/포만감 유지, 느린 네이티브 응답 중 조작 및 최종 보상 일치.

이동은 가구 배치용 빈 셀의 상하좌우 연결만 사용한다. 배치 중인 가구도 장애물로 반영하며, 두 캐릭터는 현재 셀·목표 셀과 이동 구간의 몸체 영역을 예약하여 서로 겹치거나 교차하지 않는다. 한 셀 이동 시간은 700~1200ms로 이전의 절반이다. 검증: test/ast_pet_walk.test.mjs.

폴짝임 주기는 원래의 650ms를 유지한다. 이동 시간만 절반으로 하므로 같은 한 번의 폴짝임 동안 이동하는 거리가 기존의 2배다.

시작 셀은 주변 빈 셀의 여유가 큰 실내 쪽을 우선한다. 계단 틈이나 외곽을 먼저 선택하지 않는다. 등각 투영의 위쪽 대각선 이동은 뒷모습, 아래쪽 대각선 이동은 정면으로 표시한다.

진입 HTML은 release.json을 cache:no-store로 확인한 뒤 해당 버전의 게임 모듈과 돌보기 CSS를 읽는다. 돌보기 패널에 적용 버전을 표시한다. 기존 WebView에 남은 이전 HTML은 GitHub Pages의 max-age=600 캐시가 끝나거나 캐시를 우회한 주소로 접속해야 새 로더를 받는다.

방향 보완: 옆모습을 유지하면서 바닥의 8방향 이웃 셀로 이동한다. 화면상 좌우 이동은 좌/우 옆모습, 위아래 이동은 뒷모습/정면으로 표시한다. 대각 셀 이동은 사이의 두 셀도 비어 있어야 하며 모서리를 통과하지 않는다. 네 모습 모두 실제 이동 중 등장하는 회귀 검사를 추가했다.
